# Future Huntlee Finder

A mobile-friendly static dashboard for ranking early-stage Australian master-planned growth areas.

## Files
- `index.html` – dashboard
- `data.json` – candidate database and scoring inputs

## Scoring
Weighted score /100: housing scale 18%, infrastructure 18%, schools 10%, retail 10%, transport 12%, employment 12%, early-entry potential 10%, planning certainty 10%.

## GitHub Pages
Enable GitHub Pages from the `main` branch and repository root.

## Automation-ready design
Future scans only need to update `data.json`; the page renders and ranks candidates automatically.
